# Changelog

## 1.0 - 2026-09-28
- First public release
- Position-anchored design: Position Database is the anchor sheet, linked to the trackers by ID drop-downs
- Dashboard with 7 live KPI cards, 4 3D charts, "Needs Follow-up Now" and "Upcoming Deadlines" lists
- Every dashboard element is a hyperlink to its source cell; destination headers are color-matched
- Follow-up clock stops automatically on Positive Reply, Accepted or Rejected
- Capacity: 200 positions, 200 email campaigns, 116 reply records
- 20 real sample positions from applyabroadlab.com
- Python generator so the workbook can be rebuilt from code
